Blockly Web
Blockly Web is a visual website builder built with HTML, CSS, and JavaScript. It allows users to create and customize web page elements through a visual interface without writing HTML and CSS manually.
Features
• Visual Element Creation: Create HTML elements such as headings, paragraphs, links, buttons, images, and containers.
• Element Customization: Modify element properties and styles through the editor interface.
• Nested Elements: Build hierarchical page structures by placing elements inside other elements.
• Dynamic Rendering: Generate the page preview from a tree-based data structure.
• Interactive Interface: Select elements and customize their appearance directly through the editor.
Technologies Used
• HTML5
• CSS3
• JavaScript
Project Goals
The goal of Blockly Web is to explore how visual website builders work and how HTML elements, CSS styles, and hierarchical data structures can be managed through an interactive interface.
Current Status
This project is under development. New features and improvements will be added over time.
Getting Started
1. Clone or download this repository.
2. Open index.html in your browser.
3. Start creating and customizing web elements.
